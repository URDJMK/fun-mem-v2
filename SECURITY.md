# Security

Please do not report a vulnerability in a public issue or pull request.

Report it privately on GitHub: the repository's **Security** tab, then **Report a vulnerability**.
(The maintainer turns this on under Settings → Code security → Private vulnerability reporting.)

Say what you found, how to reproduce it, and what it could expose. This app keeps families'
memories, many of them about someone who has died, so anything that could show one family's notes
to someone else, or change them, is the most serious kind of bug here.
