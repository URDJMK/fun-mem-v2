# Decisions

One short file per decision that shapes the project and would be expensive to reverse, numbered
in order: `NNNN-what-was-decided.md`, with **Context** (what forced a choice), **Decision** and
**Consequences** (what it costs, what it makes easy). A decision is never edited away: a later one
replaces it and says so.

- [0001](0001-v2-starts-from-v1-core.md) v2 starts from v1's core and server, without v1's UI
- [0002](0002-data-api-reaches-no-table.md) the Supabase Data API reaches no table
- [0003](0003-english-only-mvp.md) the MVP is English only
